# Slack Emoji Uploader Chrome Extension

Slackワークスペースに簡単にカスタム絵文字をアップロードできるChrome拡張機能です。

## 機能

- 画像ファイルをドラッグ&ドロップまたは選択してアップロード
- 複数の画像を一度にアップロード可能
- プレビュー機能付き
- シンプルで使いやすいUI

## インストール方法

1. このリポジトリをクローンまたはダウンロード
2. Chromeの拡張機能ページ（chrome://extensions/）を開く
3. 「デベロッパーモード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. このプロジェクトのフォルダを選択

## 使い方

1. Slackにログインしておく（ブラウザでSlackにログインしていれば自動的にチーム一覧を取得）
2. 拡張機能のアイコンをクリック
3. アップロード先のチームを選択
4. 画像を選択またはドラッグ&ドロップ
5. 絵文字名を入力
6. 「Slackにアップロード」ボタンをクリック

## 開発

### ファイル構成

```
├── manifest.json          # 拡張機能の設定ファイル
├── popup.html            # ポップアップのHTML
├── popup.css             # ポップアップのスタイル
├── popup.js              # ポップアップのロジック
├── background.js         # バックグラウンドスクリプト（Slack API連携）
├── images/               # アイコン画像
│   ├── icon16.png
│   ├── icon48.png
│   └── icon128.png
└── README.md            # このファイル
```

### 技術的特徴

- Slackを開かなくても絵文字をアップロード可能
- 複数のSlackワークスペースに対応
- 自動的にAPIトークンを取得
- 複数画像の一括アップロード対応
